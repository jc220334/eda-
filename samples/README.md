# 可直接体验的 PCB 样例

启动 `eda_gui.exe` 后，使用顶部菜单“样例”可直接切换以下工程：

| 菜单项 | 文件 | 内容 | 推荐体验 |
| --- | --- | --- | --- |
| 01 - 导入与布局 | `01-layout.pcbproj` | 4 个元件、4 个网络、已完成布局，无走线 | 手动点击焊盘布线、拖动和旋转元件 |
| 02 - 手动布线与过孔 | `02-manual-routing.pcbproj` | 在 01 基础上包含一条手动走线和一个过孔 | 查看手动走线、放置过孔和网络连接 |
| 03 - 自动布线 | `03-auto-routing.pcbproj` | 已自动生成 9 条走线和 4 个过孔，尚未敷铜 | 点击“连接检查”，再尝试创建敷铜 |
| 04 - 完整敷铜与验证 | `04-complete.pcbproj` | 包含完整走线、过孔、GND 敷铜和避让孔 | 查看完整结果和连接检查 |
| 05 - 核心模型演示 | `demo.pcbproj` | 简单单电阻工程 | 体验打开、移动、旋转、保存和层切换 |

`c-member-demo.pcbproj` 与 04 内容相同，保留为成员 C 的命令行验收样例。

## 推荐体验顺序

1. 打开“01 - 导入与布局”。
2. 点击一个焊盘，再点击同一网络的另一个焊盘完成手动走线。
3. 按 `Esc` 取消未完成的走线。
4. 打开“02 - 手动布线与过孔”，查看手动操作结果。
5. 打开“03 - 自动布线”，点击“连接检查”。
6. 点击“GND 敷铜”，观察底层铜皮和避让孔。
7. 打开“04 - 完整敷铜与验证”，点击“连接检查”查看最终结果。

如果没有使用菜单，也可以点击“打开工程”，直接选择目录中的 `.pcbproj` 文件。

## 命令行重新生成

```powershell
.\build\vs2026-x64\Debug\pcbdemo.exe
```

生成结果：

- `01-layout.pcbproj`
- `02-manual-routing.pcbproj`
- `03-auto-routing.pcbproj`
- `04-complete.pcbproj`
- `c-member-demo.pcbproj`
