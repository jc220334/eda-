# 成员 C 功能使用与验收说明

本文对应成员 C 负责的 PCB 业务与算法部分。当前版本已经从控制台模型演示扩展为可操作的 wxWidgets 桌面程序。

## 1. 启动

```powershell
cmake --preset vs2026-x64
cmake --build --preset vs2026-debug
.\build\vs2026-x64\Debug\eda_gui.exe
```

程序启动后自动载入：

- `examples/netlist-basic/sample.net.json`
- `examples/netlist-basic/sample.lib.json`

样例包含 4 个元件、4 个网络和 13 个已匹配引脚。

## 2. 界面操作

### 网表导入

点击“导入网表”，选择 `*.net.json`。当前界面使用样例配套元件库 `sample.lib.json` 匹配封装。

导入过程会检查：

- 格式与版本。
- 重复位号和重复网络。
- 未知封装和未知引脚。
- 同一引脚出现在多个网络。
- 少于两个连接的网络。

错误会显示在底部日志中，失败时不会留下半导入工程。

### 元件拖动和旋转

- 左键点击元件并拖动，元件按 0.5 mm 网格移动。
- 点击元件后使用“旋转元件”，或直接右键点击元件，旋转 90 度。
- 移动和旋转后，焊盘位置与网络绑定同步更新。

### 自动布局

点击“自动布局”。当前算法：

1. 计算元件包围盒。
2. 按连接数量和元件面积排序。
3. 在板框内按行放置。
4. 检查重叠和板框边界。
5. 将整组元件居中。

### 手动布线

1. 左键点击带网络的焊盘，开始绘制。
2. 在画布空白处点击可增加拐点。
3. 点击同一网络的另一个焊盘完成布线。
4. 按 `Esc` 取消当前布线。

不同网络、板框外和基础间距不足的路径会被拒绝。

### 自动布线

点击“自动布线”。当前算法：

- 为每个网络构造最小生成树。
- 优先尝试直线、L 形和多条绕行路径。
- 简单路径失败后使用 0.5 mm 栅格 A* 寻路。
- 顶层受阻时尝试底层，并在端点生成过孔。
- 失败时报告未布通网络，不删除已经生成的合法走线。

### 过孔

先点击一个焊盘确定网络，再把鼠标移到目标位置并点击“放置过孔”。也可以在自动布线换层时由程序生成过孔。

### 敷铜和避让

点击“GND 敷铜”会在底层创建 GND 敷铜，并为不同网络的焊盘、走线和过孔生成基础矩形避让孔。

### 连接和间距检查

点击“连接检查”，程序会验证：

- 同一网络的所有焊盘是否形成连通组。
- 走线是否超出板框。
- 不同网络走线之间的间距。
- 不同网络焊盘与走线之间的间距。
- 不同网络过孔与走线之间的间距。
- 敷铜是否覆盖了不同网络对象。

## 3. 保存和打开

- “保存工程”写入 `.pcbproj`。
- “打开工程”恢复层、元件、网络、走线、过孔、敷铜和避让孔。
- 保存后重新打开应保持数据完全一致。

完整自动流程生成的文件位于：

```text
samples/c-member-demo.pcbproj
```

## 4. 验证命令

```powershell
cmake --build --preset vs2026-debug
ctest --preset vs2026-debug
.\build\vs2026-x64\Debug\pcbdemo.exe
```

## 5. 当前边界

本版本满足课程基础流程，但不是工业级 EDA：

- 自动布局是规则式排布，不包含热仿真或复杂约束。
- 自动布线使用简化间距模型与栅格 A*，不保证复杂板卡全部布通。
- 敷铜使用基础矩形避让孔，不包含热焊盘、孤岛处理和优先级。
- 当前只提供顶层和底层的通孔换层。

这些限制不影响网表导入、布局、布线、过孔、基础敷铜和完整演示流程的验收。
